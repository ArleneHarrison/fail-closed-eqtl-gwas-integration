# v0.1.0 — submission release

**Archived release DOI:** [10.5281/zenodo.22241027](https://doi.org/10.5281/zenodo.22241027)  
**All-versions concept DOI:** [10.5281/zenodo.22241026](https://doi.org/10.5281/zenodo.22241026)

This is the first public, versioned release of the software and reproducibility package accompanying the manuscript *An executable fail-closed contract for regional eQTL–GWAS integration: a multi-tissue technical evaluation in coronary artery disease and heart failure*.

## Included verification record

- 93 prior-verification Python tests.
- 25 external-validation Python tests.
- Two version-pinned R contract checks.
- Frozen multi-tissue cardiovascular protocol and implementation metadata.
- Terminal registries, aggregate audit outputs, figures, tables, environment records, and SHA-256 manifests.

## Scope

The release supports computational-reliability, deterministic-gating, numerical, LD-portability, and controlled downstream-sensitivity claims. It does not claim new biological associations, causal effects, drug targets, clinical validity, clinical utility, or general superiority over existing tools.

## Data and licensing

Raw third-party GWAS, eQTL, reference-genotype data, posterior objects, and controlled-access material are excluded. Software is Apache-2.0; project-authored documentation, figures, tables, and generated audit data are CC BY 4.0. See `LICENSE_SCOPE.md`.
